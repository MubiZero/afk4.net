# Возможности AFK4.NET для сайта: опись (15.11.2026)

Источник для окон и текстов сайта. Собрана по коду (`src/AFK4.Platform.Api/*`, `OrganizationAdmin.Web`, `Player.Shell.Web`, `afk4_customer_app`) и `docs/product/AFK4-MVP-PRD.md`. Статус «есть в коде» ещё не «готово» для клуба: метку «готово» ставит владелец. Цены и тарифы SaaS на сайт не выносим (в PRD они «to be confirmed»).

| Окно сайта | Что внутри | Статус |
|---|---|---|
| Карта зала | Залы и места, цвет и остаток времени у каждого ПК; команды: запереть/открыть, перезагрузить, выключить, включить по сети, сообщение на экран гостя, выход; выбрать несколько мест сразу; режим обслуживания (рабочий стол для персонала); места без ПК (приставки, ТВ) | есть в коде |
| Сессии и тарифы | Старт, продление, перенос, пауза, конец; тарифы с версиями; пакеты времени; долг «потом оплатит»; бонусы и кешбэк; журнал денег, который не стирается | есть в коде |
| Касса и бар | Товары, остатки, штрихкод, малый остаток; продажа, возврат, отмена; смена: открытие, закрытие, расхождение; чеки; чаевые администратору; лимиты и подтверждение денежных действий | есть в коде |
| Гости | Список гостей, поиск дублей, брони, отзывы, друзья, приглашения друзей, кешбэк, подарок на день рождения, турниры, события клуба, новости | есть в коде |
| Экран гостя | Вместо Windows экран клуба: вход по телефону и PIN или QR, выбор времени, игры, бар, пополнение, позвать администратора, итог с оценкой визита и чаевыми, системная панель (язык, раскладка, звук); запреты Windows | есть в коде, проверено на Win11 и Win7 (проба) |
| Приложение игрока | Каталог клубов, бронь, пополнение, пакеты, заказ в баре, кешбэк, приглашения, отзывы, друзья, турниры, управление сессией, вход на ПК по QR (Flutter: Android и веб) | в коде; **подтвердить статус** |
| Один аккаунт на сеть | Личность, PIN и репутация общие для клубов, деньги клубные (модель «общий котёл») | в коде; **подтвердить статус** |
| Заказ в баре с телефона | Игрок заказывает из приложения, очередь заказов у администратора | в коде; **подтвердить статус** |
| Игры и кеш | Библиотека игр клуба; кеш игр встроен в ПК администратора: Steam и Epic берут обновления по сети клуба | кеш есть; «раздачу игр по кешу» владелец называл планом: **подтвердить границу** |
| Владелец | Роли и права, журнал «События» (кто что сделал), отчёты (Сводка, Смены и касса, Выручка), несколько филиалов, итоги в Telegram, перенос гостей из другой программы | есть в коде |
| Когда всё плохо | Касса без интернета; свет пропал, время гостям вернулось; здоровье ПК (температура видеокарты, диски, место); бэкапы каждый час; обновления подписанными пакетами с откатом | есть |
| Подключение | Мастер установки, регистрация ПК, демо Панели, три языка | есть |

Не выносим на сайт: цены и лимиты тарифов; реклама на бесплатном тарифе; номера Telegram-бота, внутренние названия.

Планы владельца без кода (снеки «в полном виде», мобильное приложение «как продукт», раздача игр по кешу сверх обновлений) добавляются только после подтверждения границы.
