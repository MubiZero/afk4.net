# Публичный сайт afk4.net

Последнее обновление 2026-10-29.

Лендинг AFK4.NET для владельцев клубов. Заодно на нём лежит то, что
[SignPath Foundation](https://signpath.org/terms) требует от проекта, чтобы бесплатно подписывать установщик
(Authenticode): описание возможностей, страница загрузки, «Code signing policy» с дословной строкой SignPath и ролями
команды, политика конфиденциальности, перечень изменений в Windows и инструкция по удалению.

## Где что

- **Исходник** — `site/`:
  - `content.ts` — тексты на трёх языках одной структурой; язык без нужной строки не соберётся;
  - `build.ts` — сборщик без зависимостей;
  - `styles.css`;
  - `img/` — настоящие снимки демо-Панели и экрана игрока с обрезанной полосой «Демо».
- **Сборка** — `bun site/build.ts` → `site/dist/`. Адреса:
  - русский — `/`;
  - таджикский — `/tg/`;
  - английский — `/en/`.

  Страницы: `index.html`, `download.html`, `code-signing.html`, `privacy.html`. Локальный просмотр — конфигурация
  `public-site` в `.claude/launch.json` (порт 4180).
- **Выкладка** — `.github/workflows/public-site.yml`: на каждую правку `site/**` в `main` собирает и выкладывает на
  Cloudflare Pages, проект `afk4-site`.
  - Секрет `CLOUDFLARE_PAGES_API_TOKEN` — узкий токен «Pages: изменение» этого аккаунта.
  - Переменная `CLOUDFLARE_ACCOUNT_ID`.
  - GitHub Pages этого репозитория занят демо-Панелью (`demo.afk4.net`), а второго сайта из одного репозитория Pages
    не даёт.
- **Домены:** `afk4.net` и `www.afk4.net` — свои домены проекта Pages.
- **Без сторонних ресурсов:**
  - шрифт системный (Segoe UI на Windows, Roboto на Android; оба знают таджикские буквы);
  - нет cookie, счётчиков и внешних скриптов;
  - CSP в `_headers` разрешает только свой домен. Политика конфиденциальности это и обещает.

## Правила текста

- Только то, что программа уже умеет. Новая возможность попадает на сайт вместе с PR, который её вводит.
- Перечень «Что установка меняет в Windows» обязан совпадать с кодом агента и мастера. SignPath запрещает менять
  систему без предупреждения. Добавили правило брандмауэра, запись в реестр или файл — допишите сюда.
- Строку «Free code signing provided by SignPath.io, certificate by SignPath Foundation.» не переводить: SignPath
  требует её дословно.

## Что ещё нужно для подписи

1. **Выпуск на GitHub.** SignPath подписывает только уже выпущенное. Кнопка «Скачать» ведёт на
   `releases/latest`, а выпусков пока нет.
2. **Заявка в SignPath Foundation** — от владельца, с его учётной записью и двухфакторной проверкой.
3. **Уборка при удалении.** Сейчас удаление оставляет правила брандмауэра, блок в `hosts` и выключенный «быстрый
   запуск», а сайт честно описывает, как убрать их вручную. Лучше, чтобы это делал сам деинсталлятор.
