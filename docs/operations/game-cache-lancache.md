# Кеш игр клуба (LANCache)

Обновление игры весом 50 ГБ на 20 ПК — это 1 ТБ из интернета. С кешем игра приходит из интернета один раз, а остальные
ПК забирают её по локальной сети на скорости гигабитной сети. Заявка в Valve не нужна: используем открытый
[LANCache](https://lancache.net). Steam сам ищет кеш по имени `lancache.steamcontent.com`. Если кеш не отвечает,
Steam качает из интернета как обычно.

Последнее обновление 2026-10-27.

## Как это устроено у нас

- В клубе стоит отдельный сервер с LANCache (Docker на Linux).
- Его адрес задают в Панели: «Управление» → «Игры» → карточка «Кеш игр клуба».
- Сердцебиение передаёт адрес агентам филиала. Каждый агент раз в минуту проверяет кеш: `GET http://<адрес>/lancache-heartbeat`,
  ожидаемый ответ — `204` с заголовком `X-LanCache-Processed-By`.
  - Кеш отвечает — агент записывает в `C:\Windows\System32\drivers\etc\hosts` свой блок между метками `# AFK4 game cache begin/end`:
    имя Steam и 15 имён Epic Games (список [uklans/cache-domains](https://github.com/uklans/cache-domains)). Затем сбрасывает
    кеш DNS Windows.
  - Кеш не отвечает — блок убирается. Steam и без этого обошёл бы молчащий кеш, а Epic упёрся бы в мёртвый адрес.
  - Чужие строки `hosts` агент не трогает.
- Роутер и DNS клуба перенастраивать не нужно.
- Панель показывает, сколько ПК видят кеш: «Кеш видят 7 из 9 ПК». После смены адреса прежние отметки сбрасываются.
- Адрес принимается только частный IPv4 (10.x, 172.16–31.x, 192.168.x). Адрес из интернета увёл бы загрузки всех ПК на
  чужой сервер.

Код: `src/AFK4.Agent.Service/Network/GameCacheService.cs`, `src/AFK4.Platform.Api/Endpoints/GameCacheEndpoints.cs`,
`src/AFK4.Shared.Contracts/Games/GameCacheContracts.cs`.

## Что нужно клубу

- **Сервер.** Любой ПК или мини-ПК с Linux (Ubuntu Server), 4 ГБ памяти и больше.
  - **Диск под кеш** — отдельный от системы, от 2 ТБ. SSD быстрее раздаёт первые часы после выхода обновления, но HDD тоже работает.
  - **Сеть.** Гигабитный кабель до коммутатора зала. Wi‑Fi не годится.
- **Постоянный адрес сервера.** Резервирование по MAC в DHCP роутера (например, `192.168.1.10`). Если адрес сменится,
  агенты увидят, что кеш молчит, и вернут ПК к обычным загрузкам. Но кеш при этом простаивает.
- **Электричество.** Кеш-сервер лучше держать на том же ИБП, что и роутер. Без кеша клуб работает, просто качает из интернета.

## Установка (один раз, ~20 минут)

```bash
sudo apt-get update && sudo apt-get install -y docker.io docker-compose-v2 git
git clone --depth=1 https://github.com/lancachenet/docker-compose lancache
cd lancache
```

В файле `.env` задайте:

- `LANCACHE_IP=192.168.1.10` — адрес этого сервера;
- `CACHE_ROOT=/srv/lancache` — папка на диске под кеш;
- `CACHE_DISK_SIZE=1800g` — немного меньше размера диска;
- `UPSTREAM_DNS=8.8.8.8` — нужен только для контейнера DNS, см. ниже.

```bash
sudo docker compose up -d monolithic
curl -si http://192.168.1.10/lancache-heartbeat | head -3   # ждём «204 No Content»
```

Затем в Панели: «Управление» → «Игры» → «Кеш игр клуба» → адрес → «Сохранить адрес». Через минуту карточка покажет,
сколько ПК видят кеш.

## Riot, Battle.net и остальные

Riot и Battle.net раздают игры с имён по маске (`*.dyn.riotcdn.net`), а `hosts` маски не понимает. Для них нужен DNS
клуба:
- запустите и контейнер DNS: `sudo docker compose up -d`;
- в DHCP роутера выдайте адрес сервера как единственный DNS.

Это меняет сеть всего клуба, поэтому делать это стоит вместе с тем, кто отвечает за роутер. Steam и Epic работают и без
этого шага.

## Проверка, что кеш работает

- В Steam на ПК клуба скачайте игру, затем скачайте её же на другом ПК. Второй раз скорость должна упереться в локальную
  сеть (около 100 МБ/с на гигабите), а не в интернет.
- На сервере: `sudo docker compose logs -f monolithic`. Строки с `HIT` — отдано из кеша, `MISS` — скачано из интернета.

## Чего кеш не делает

- Лицензий не даёт. Каждый игрок входит в свой аккаунт Steam. Один аккаунт на все ПК нарушает соглашение Steam.
- Не ускоряет загрузки по HTTPS: LANCache кеширует только HTTP, на котором Steam и Epic отдают игры.
- Steam Local Network Game Transfers (передача между ПК без сервера) — отдельная настройка клиента Steam. Агент её пока не
  выставляет: ключ её конфигурации надо найти на живом ПК со Steam.
