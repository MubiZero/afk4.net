# Windows 7 на ПК клуба

Последнее обновление 2026-10-29.

## Зачем

Почти половина ПК в клубах Таджикистана — Windows 7, в том числе 32-битная. Это и игровые ПК (CS 1.5/1.6, Quake,
Dota 1), и ПК администратора. .NET 10 и свежий WebView2 на Windows 7 не запускаются.

Решение владельца (2026-10-29): AFK4 остаётся на .NET 10, сервер на .NET, экраны на WebView2, код открытый. Программы
на ПК клуба собираются ещё и под .NET Framework 4.8. Если установщик видит Windows 7, он докачивает нужное для неё.
XP не поддерживается.

## Как устроено

| | Windows 10 и 11 | Windows 7 SP1 (x64 и x86) |
|---|---|---|
| Платформа программ | .NET 10, своя копия в установщике | .NET Framework 4.8, докачивается, если её нет |
| Экраны (игрок, Панель, мастер) | WebView2 из Windows или из установщика | WebView2 109, последний для Windows 7, докачивается |
| WebView2 SDK в сборке | 1.0.4314 | 1.0.1518, новее не запускается на Windows 7 |
| Сеть | система выбирает TLS 1.2/1.3 | программа сама просит TLS 1.2 (`UseTls12OnWindows7`) |
| Канал команд (SignalR) | WebSocket | Windows 7 в .NET Framework не умеет клиентский WebSocket — SignalR сам переходит на SSE |

Код один. Каждая программа на ПК (агент, экран игрока, Панель, мастер) и их общие библиотеки (контракты,
ядро мастера, локализация) собираются в два варианта: `net10.0`/`net10.0-windows` и `net48`. Сервер и тесты остаются
на .NET 10.

Недостающее в 4.8 закрывают:
- **Пакет Polyfill** — заплатки на уровне исходников, в программу не попадают отдельной библиотекой.
- **`src/Compat/`**:
  - ключи P-256 в PEM и PKCS#8 байт в байт как у .NET 10;
  - `NativeLibrary`;
  - канал со списком доступа;
  - код ответа у `HttpRequestException`;
  - `string.Create` и `Replace` с учётом регистра.
- **`DateOnly`/`TimeOnly`** в контрактах — с тем же JSON, что у .NET 10.
- **Brotli** частей дельта-обновлений — BrotliSharpLib.
- **Пояса IANA** («Asia/Dushanbe») — TimeZoneConverter.

Проверка: `tests/AFK4.NetFramework.Tests` (net48, только на Windows; задача CI «Build And Test Windows») сверяет
это с эталонами, снятыми с настоящего .NET 10.

## Ход работ

1. **Сделано** (ветка `feat/netfx48`): все программы на ПК собираются под net48; тесты совместимости; сборка
   установщика явно берёт .NET 10.
2. Сборка net48-вариантов в CI: x64 и x86, пакеты для докачки.
3. Установщик: бандл (Burn — родной код, работает на Windows 7) смотрит версию Windows и разрядность. На Windows 7
   он докачивает с `updates.afk4.net`:
   - .NET Framework 4.8 — только если её нет;
   - WebView2 109 нужной разрядности;
   - net48-сборки программ.

   На Windows 7 без обновления KB4474419 (подписи SHA-2) .NET 4.8 не ставится — установщик скажет об этом.
4. Обновления дельтой по варианту: сервер знает платформу и разрядность ПК из сердцебиения и отдаёт свой манифест.
5. Стенды Windows 7 x64 и x86 (образы — от владельца, `~/VMs/iso`), приёмка всех сценариев.
