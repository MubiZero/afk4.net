# План к пилоту и дальше (25.10.2026)

Цель: качественный релиз и запуск на 1–2 пилотных клубах в Таджикистане, затем лидерство на местном рынке
(плохой и дорогой интернет, отключения света, слабые ПК, наличные, русский и таджикский).

Основа плана — пять исследований 25.10.2026: аудит готовности к пилоту, обзор серверной части, обзор
клиентов (агент, оболочка, Панель, мастер, веб, Flutter), рынок и конкуренты, версии стека. Каждая находка
ниже проверена по коду хотя бы одним из них; что проверено мной лично — помечено «✓».

## 1. P0 — то, во что пилот упрётся в первую неделю

### Деньги
- **Выручка в «Сводке» и снимках считается дважды** ✓. `BranchRevenue.PosNet` складывает все платежи, а `Gameplay` — списания за игру; наличная оплата гостевой сессии пишется и тем, и другим (`SessionBillingService.cs` ~510, `EfSessionCheckoutService.cs` ~334). Отчёт смены считает иначе — цифры расходятся. → одно правило выручки + тест паритета «Сводка = смена».
- **Онлайн-пополнение Eskhata: заявка `fulfilled` ставится до зачисления** ✓ исправлено: сначала зачисление (идемпотентно по `intentId`), потом отметка; оплата отменённой заявки тоже зачисляется; сверка с банком раз в 5 мин подбирает оплаты, о которых не дошёл вебхук.
- **Нет таймаута клиента Eskhata** ✓ исправлено: 15 с, таймаут отвечает «занято», а не 500. «Заказ в банке до сохранения заявки» оказался безвреден: QR без сохранённой заявки игрок не видит, платить нечем.
- Возвраты/пакеты/неявки по-разному входят в выручку дашборда и смены. Ранний уход гостя не возвращает наличные автоматически. Сессии из кошелька без чека.

### Связь и отключения света
- **Панель теряла живые данные навсегда** после обрыва > ~42 с или старта без сети. ✓ исправлено (#632): переподключение без предела, stateful reconnect, тишина 60 с; HTTP/2 + сжатие у агента.
- **Файлы состояния агента писались неатомарно** — отключение света стирало оплаченную аренду. ✓ исправлено (#633).
- Офлайн-карта зала в Панели не перечитывалась сама и не досылала очередь блокировок после возврата связи. ✓ исправлено: повтор с паузой до 30 с, пока карта офлайн, событие `online` будит сразу, очередь досылается при любом возврате живой карты.
- Время после отключения света: `PlatformSyncedTimeProvider` держал поправку в памяти, аренда до первой синхронизации проверялась по сырым часам ПК (севшая батарейка BIOS). ✓ исправлено: на диске пара «время платформы / аптайм», до связи время не ниже неё. «Не стирать аренду до синхронизации» не сделано: спасает только от часов, ушедших вперёд, а это редкость (батарейка откатывает назад).
- Только деньги онлайн: старт сессии и оплата без интернета невозможны (сознательно в PRD). На рынке это главный критерий выбора ПО — см. §2.

### Лимиты и устойчивость сервера
- **Лимит `player-public` — 10/мин на IP**, а весь клуб сидит за одним NAT: вечерний наплыв → 429 всему залу; вебхук банка в том же ведре. ✓ исправлено (#637): пределы под NAT клуба, у сессии игрока и вебхука свои вёдра.
- **Проверка токена сотрудника и админа читает все активные токены** на каждый запрос. ✓ исправлено (#637): поиск по `TokenHash` в SQL.
- **`DevSeed` по умолчанию удаляет базу** без проверки хоста. ✓ исправлено (#637): отказ, если не localhost / не `_dev`/`_test`.
- Почти нет логов в деньгах и платежах, нет correlation id, `/api/health` не проверял базу (✓ #645: `/api/health/ready`). Аудит денежных действий писался после коммита (✓ #648 и следом: в транзакции с деньгами; кроме денежных действий с одобрением: там деньги и отметка «одобрено» — разные коммиты, но сбой между ними лечится повторным одобрением по тому же ключу идемпотентности; врёт только отклонение или истечение заявки сразу после такого сбоя — окно в миллисекунды, сознательно не чиним).
- Очереди уведомлений и биллинга не захватывают строки атомарно (накладка контейнеров при выкладке → двойные SMS), зависшие `Sending` не сбрасываются. ✓ исправлено (#644): захват условной записью, аренда 5 мин, итог по строке.

### Клиенты
- **Оболочка: сбой WebView2 → нет перехвата клавиш и вечная плашка** «Восстанавливаем соединение…» (не локализована). ✓ исправлено: перехват до WebView, плашка локализована и честная («позовите администратора»), корневой `ErrorBoundary` в Player.Shell.Web перезагружает экран. Выход процесса для супервизора отложен: до перезапуска (до интервала сердцебиения) рабочий стол был бы открыт — сначала разгрузка цикла агента.
- Один последовательный цикл агента держал и блокировку, и тяжёлую синхронизацию (игры, витрина, железо) — на плохом канале команды ждали десятки секунд. ✓ исправлено: синхронизация в фоне (одна за раз), оболочка и запреты — свой цикл раз в 3 с. Льгота и аренда остались в цикле сердцебиения: там их гонка с продлением уже закрыта порядком.
- Панель: 2,3 МБ одним куском (три каталога локалей внутри; ✓ срез каталога без чужих разделов — 1,76 МБ / 441 КБ gzip), секундный тик перерисовывал всё приложение (✓ исправлено: отсчёт ведут сами плитки) — на слабом кассовом ПК это заметно. Хоткеи не работали на кириллической раскладке (✓ исправлено: сверка по физической клавише).

### Приёмка на живом ПК (никакой код это не заменит)
Windows 10 и 11 x64 с GPU: установка бандла (в т. ч. WebView2 из бандла, silent по коду), SmartScreen, киоск и снятие киоска, игры, вход по номеру/QR, офлайн 10–20 мин с перезапуском службы и перезагрузкой, обновление и откат, касса при 100/125 %, выдёргивание из розетки.

## 2. P1 — чем выигрываем рынок

По рынку (Senet, ggLeap, Gizmo, SmartShell, Langame, iCafeCloud, SmartLaunch): у конкурентов обновление игр и офлайн — дорогие тарифы или бездисковые схемы; про электричество и таджикский язык не говорит никто.

1. **Настоящий офлайн у стойки**: посадить гостя, взять наличные, закрыть смену без интернета, потом досинхронизировать без двойных списаний. Дизайн и этапы — `docs/roadmap/offline-front-desk.md`. ✓ 27.10: этапы 0–4 (#662 честные кнопки, #663 агент, #665 ключи, #666 хост, #668 журнал, #669 касса в Панели; #667 «запереть» не трогает чужую сессию). Осталось: приёмка на VM с выдернутой сетью, товары без связи, закрытие смены без связи.
2. **Свет пропал — сессия не пропала**: возобновление после отключения (остаток времени, честный отчёт «что потеряно»), реакция на ИБП (корректное завершение). Ни один конкурент это не продаёт.
3. **Игры качаются один раз на клуб** (владелец 27.10: можно без заявки в Valve — открытый LANCache, lancache.net: DNS-кэш Steam/Epic/Battle.net/Riot в Docker на сервере клуба):
   - сейчас: Steam Local Network Game Transfers в режиме «любой пользователь» на всех ПК (агент выставляет настройку; ключ конфига надо найти на живом ПК со Steam) + ночное обновление на одном «сид»-ПК;
   - параллельно: Steam PC Café (официальный кэш Valve) — решение владельца (§0);
   - позже: LANCache на мини-ПК для Epic/Battle.net/Riot;
   - нельзя: один Steam-аккаунт на все ПК (нарушает соглашение Steam).
4. **Владелец с телефона**: выручка, смена, расхождения кассы, офлайн-ПК, пуш о подозрительном (Telegram-бот или приложение владельца). ✓ 27.10: «Отчёты в Telegram» — привязка чата QR-кодом из Панели, итоги смены, тревога кассы, сводка за вчера в 9:00 (#660, #661). Включается токеном бота в Coolify (`Telegram__BotToken`). Осталось: ПК без связи, отчёт о досылке офлайн-журнала.
5. **Обновления нашего ПО без трафика**: дельта по манифесту файлов (#629–#631; включение — после приёмки на живом ПК) + закреплённый SDK (#628) + MSI агента 171 → 59 МиБ (#627).
6. **Здоровье ПК**: температуры, диск, вентиляторы, WoL, расписание выключения.
7. **Таджикский язык везде** (носитель-вычитка), формат дат/денег по локали (сейчас `'ru-RU'` захардкожен в Панели).
8. **Местные оплаты**: Alif/Korti Milli QR, когда появится API; до тех пор наличные первым классом.

## 3. P2 — современность и согласованность

- **Версии**: GitHub Actions на Node 24, nginx 1.27 (EOL) → 1.30, vite (advisories), happy-dom (advisory), NuGet/npm патчи, Postgres в CI = staging, Flutter CI ≠ lock — отдельный PR (в работе). Мажоры отдельно: TypeScript 7 (нативный компилятор), AWSSDK.S3 4, Firebase 5/17, intl-messageformat 12.
- **Единые клиентские основы**: один HTTP-клиент с повторами для GET (сейчас 4 самописных, повторов нет), TanStack Query для кэша и дедупликации, один `ErrorBoundary`/диалог/тост в `@afk4/ui`, React Compiler в Панели.
- **Сервер**: ProblemDetails и глобальный обработчик ошибок (сейчас 4 формата), авторизация «закрыто по умолчанию» через политики вместо 235 ручных проверок, OpenTelemetry + JSON-логи, health-check с базой, очистка растущих таблиц, версия API/окно совместимости клиентов.
- **Сеть**: HTTP/3 агенту на Windows 10 недоступен (QUIC только Windows 11) и не нужен; выигрыш — в сжатии, HTTP/2, бесконечном реконнекте и батчинге мелких отчётов агента.
- **Платформа клиентов**: Windows 10 1809+/LTSC и 11; урезанные сборки — проверка при установке (сборка ОС, SSE3, WebView2 после установки, запасной Fixed Version).
