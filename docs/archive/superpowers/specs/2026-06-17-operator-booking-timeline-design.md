# Редизайн вкладки «Брони» Operator.App → таймлайн-гант

**Дата:** 2026-06-17
**Область:** `src/AFK4.Operator.App.Web` — вкладка «Брони» (`BackendBookingWorkspace`)
**Тип:** редизайн UI + починка рабочего процесса (visual + workflow)

## Контекст и проблема

Текущий экран «Брони» — фиксированная сетка из 4 квадрантов:
лента броней (только «сегодня»), панель выбранной брони с действиями,
онлайн-заявки, форма создания. Болевые точки:

- **Только «сегодня».** `fromUtc`/`toUtc` жёстко зашиты на текущий день —
  нет навигации по датам, будущих/прошлых броней не видно.
- **«Лента» — просто список.** Названо timeline, но временно́й оси нет:
  не видно свободных окон и наложений.
- **Полу-реализованные действия.** «Перенести» берёт первое попавшееся
  свободное место (`readySeats.find(...)`), форма создания тоже сама выбирает
  место — оператор не управляет, куда сажать.
- **Несогласованные состояния.** Карта уже использует `Skeleton`/`EmptyState`,
  а Брони рисуют самодельную карточку-заглушку.
- **Форма создания вечно занимает четверть экрана**, даже когда не нужна.

Бэкенд уже всё умеет: `search` принимает произвольный `fromUtc`/`toUtc` и
фильтры `state`/`source`; `create`/`update` принимают явный `seatId`.
**Поэтому весь редизайн — чистый фронт, без изменений API.**

## Решение: таймлайн-гант с боковым drawer

Экран сохраняет общий каркас `workspace-screen` (как у Карты).

### 1. Шапка (`screen-head`)
- надзаголовок + «Брони» слева;
- справа: **навигатор дат** `‹ [Сегодня, 17 июня] ›`, чип статуса загрузки,
  кнопка `+ Бронь`.

### 2. Полоса показателей (`state-strip`)
Существующие `StateFlag`: Свободно / Занято / Проблемы / Броней / Заявок.
Оставляем как есть — совпадает с Картой.

### 3. Лейн онлайн-заявок (условно)
Тонкая полоса над гантом, **показывается только если есть онлайн-заявки без
назначенного места** (`source==='online' && state==='pending' && !seatId`):
карточки заявок с inline-кнопкой «Принять» и «Уточнить». Клик → drawer.
Заявки **с** местом ложатся прямо на грид как блоки (тон `online`).

### 4. Гант (основная область)
- **Левый жёлоб:** названия мест, сгруппированы по залам (заголовок зала как
  `zone-group-head` на Карте, под ним строки-места). Порядок залов/мест — из
  `floorMapState` (уже отсортировано).
- **Правая область:** липкая шапка с часовыми засечками + по строке на каждое
  место; брони — блоки, позиционируются абсолютно:
  `left = (старт − началоОси)/диапазон`, `width = длительность/диапазон`.
- **Вертикаль «сейчас»** — если текущее время попадает в окно оси.
- **Ось авто-подгоняется под день:** от «чуть раньше первой брони» до «чуть
  позже последней», с минимальным диапазоном ~6ч; если броней нет — окно вокруг
  текущего времени. Кламп в пределах суток. Горизонтального скролла нет.
- **Много мест → вертикальный скролл** (жёлоб + строки скроллятся вместе),
  шапка времени липкая.
- **Клик по пустому участку строки** → drawer в режиме создания с
  предзаполненными местом и временем.
- Блок: время + имя гостя; цвет/левый бордер = статус (confirmed=success,
  online/pending=warning, seated=accent). Отменённые на гриде не показываем.
- Выбранный блок подсвечен.

### 5. Боковой drawer справа
- **Режим деталей** (клик по блоку): статус, время, зал·место, длительность,
  клиент, комментарий, источник + кнопки **Открыть на карте / Посадить /
  Перенести / Отмена**.
  - «Перенести» открывает **выбор места** из свободных (вместо «первого
    попавшегося»).
- **Режим создания** (`+ Бронь` или клик по пустой ячейке): форма (имя, телефон,
  старт, длительность) + **выбор места** из свободных (предзаполнен, если открыт
  из ячейки) + кнопка создать.

## Данные

- Тот же `clients.reservations.search`, но `fromUtc`/`toUtc` берутся из стейта
  `selectedDate` (дефолт — сегодня). Стрелки ‹ › меняют дату → перезапрос.
- Ось считаем из `min(старт)` и `max(старт + длительность)` за день, с отступами,
  кламп к мин. диапазону (~6ч) и в рамках суток; если броней нет — окно
  `сейчас − 1ч … сейчас + 5ч` (в пределах суток).
- Строки — места из `floorMap.seats`, группировка по залам. Блоки раскладываем
  по `seatId`. Бронь с неизвестным местом / заявка без места → лейн заявок.

## Состояния (примитивы Карты)

- **Загрузка** → `Skeleton`-строки через `useDeferredFlag` (отложенный спиннер,
  чтобы быстрые ответы не флешили).
- **Пусто** (нет броней на день) → `EmptyState` («На этот день броней нет» +
  действие «+ Бронь»).
- **Ошибка** → `FeedbackNotice` с конкретным текстом (`projectOperatorError`).
- **Фидбэк действий** → существующий `FeedbackNotice` в drawer.

## Структура файлов (не плодим монолит)

Текущий `BackendBookingWorkspace.tsx` ~400 строк и вырастет — режем:

- `BackendBookingWorkspace.tsx` — контейнер: загрузка, стейт, навигация дат,
  сборка модели, рендер подкомпонентов.
- `booking/BookingTimeline.tsx` — гант (жёлоб + строки + ось + «сейчас» + блоки).
- `booking/BookingDrawer.tsx` — drawer (деталь + создание).
- `booking/BookingRequestsLane.tsx` — лейн заявок.
- `booking/bookingModel.ts` — чистые хелперы (ось, раскладка блоков, группировка
  мест, маппинг тонов) — под юнит-тесты.
- CSS: переписываем `styles/10-booking.css` под гант.

Переиспользуем: `StateFlag`, `EmptyState`, `Skeleton`, `FeedbackNotice`,
`useDeferredFlag`, существующие хелперы (`formatTime`, `addMinutes`,
`toDateInputValue`, `toDateTimeInputValue`), пермишены, i18n.

## i18n

По максимуму существующие `op.booking.*`; новые ключи (навигация дат, ось/часы,
лейн заявок, выбор места, пустой день, «сейчас») добавляем **реальными
переводами во все локали** (ru/en/tg). Никакого фейк-паритета; tg помечаем на
ревью при сомнении.

## Тесты

- Юнит на `booking/bookingModel.ts`: расчёт оси (0 броней, 1 бронь, наложения,
  мин-диапазон, кламп суток), раскладка блоков по местам, группировка.
- Существующие тесты, ссылающиеся на брони (`App.test`, `CommandPalette.test`,
  `QuickActionsMenu.test`, `operatorApiClients.test`), держим зелёными; правим,
  если завязаны на старый DOM.

## За рамками (YAGNI)

- Drag-создание / drag-resize блоков и drag-перенос между местами. Создание —
  клик по ячейке + форма; перенос — выбор места из списка.
- Неделя / мульти-день. Только день + навигатор дат.
- Сложная раскладка наложений в одной строке (саб-лейны). Редкий случай —
  блоки просто наложатся, выбор по клику работает.
