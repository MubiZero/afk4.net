# P6. Панель, группа 1

Дата: 2026-09-25. Спека: `../specs/2026-09-24-player-shell-rewrite-design.md`, §6.3, §6.6, §11.
Решения владельца: `admin-app-competitor-takeaways` (24.09) — команды ПК, выделение нескольких
мест, полное меню места, настройки шелла у клуба, библиотека игр и каталог платформы, страница
отзывов. Опирается на P2 и P5 (стопка #449–#479).

## Что нашло чтение кода

- Меню места и команды ПК работают (#460), но команды, кроме блокировки, живут только в
  карточке места; выбрать сразу несколько мест нельзя вовсе.
- Список игр — в `bootstrap.json` каждого ПК (`Agent:LauncherApps`); ни каталога, ни
  библиотеки клуба на сервере нет. Даты рождения у игрока нет — возраст игры можно только
  показать, не проверить.
- Настройки оболочки у клуба — только профиль защиты (P5d, P5e).
- Отзывы игроки пишут (и из приложения, и с итога сессии на ПК), а клуб их в Панели не видит.

## Нарезка

### P6a. Несколько мест и полное меню — сделано

- Ctrl/⌘-клик добавляет место к выбору, Shift-клик — места подряд в порядке карты, «Выбрать
  зал» — весь зал; Esc снимает выбор. Выбор для команды — отдельно от места, открытого в
  карточке, и не запускает сессию на свободном.
- Полоса выбранных мест: заблокировать, сообщение, выход игрока, разбудить, перезагрузить,
  выключить, обслуживание. Подтверждение со списком — кому уйдёт и кому нет с короткой
  причиной («идёт сессия», «не на связи»); правило для каждого места то же, что у его карточки
  (`pc/pcBulk.ts`). Команды уходят по четыре разом по существующему пути одного ПК — сервер
  проверяет каждую сам; итог называет, что не вышло.
- Меню места по правому клику несёт все команды ПК карточки; закрытые — с короткой причиной.
  Правый клик по одному из выбранных — меню для всех выбранных.

### P6b. Каталог игр платформы и библиотека клуба — сделано

- Каталог — в Platform Control: название, описание, жанр, возраст, способ запуска по
  умолчанию (Steam по AppID, Epic, Riot, Battle.net, свой exe), обложка из медиа-хранилища.
  **Допущение:** обложки загружает администратор платформы и отвечает за права на них; без
  обложки карточка рисуется по названию. Открытый вопрос спеки (§6.6) остаётся за владельцем.
- Библиотека клуба — в Панели: добавить из каталога или своё, путь запуска и аргументы,
  «без сессии», порядок. Агент берёт её отдельным запросом по версии в сердцебиении, а не в
  профиле защиты: профиль — что запрещено, библиотека — что предложено, и новая игра не должна
  перезаписывать политики HKLM на всём зале. Пустая библиотека клуба — агент берёт прежний
  `LauncherApps` из `bootstrap.json`.
- Обложки агент кэширует рядом с будущей витриной (P7); оболочка показывает их из кэша.
- Сделано: `catalog_games`, `branch_games`, `branch_game_libraries` (версия); Platform Control
  «Каталог игр» (право `platform.games.manage`), Панель «Управление → Игры» (право
  `organization.games.manage` у владельца, управляющего и техника), `GET /api/devices/{id}/games`
  по ключу устройства, `GameLibraryVersion` в сердцебиении. Цель запуска проверяется на сервере и
  в формах: AppID Steam — цифры, id лаунчеров — `[A-Za-z0-9_.:-]`, свой exe — полный путь Windows к
  `.exe`. Каталог правит игру — версии библиотек клубов с ней растут.
- P6b-2 — агент: `Games/GameLaunchResolver.cs` (Steam `-applaunch`, Epic ссылкой через
  `url.dll` — в киоске нет проводника, Riot и Battle.net их клиентами), `GameLibraryService` —
  один список на показ и на разрешение запуска, запасной — `bootstrap.json`; обложки в
  `%ProgramData%\AFK4\Showcase\covers`, хост — виртуальный хост `showcase.afk4.local`.

### P6c. Настройки оболочки у клуба — сделано

Выключать свободный ПК через N минут простоя, текст правил клуба на экране ПК, игры и
программы, которые стартуют сами при начале сессии.

- «Защита ПК» стала «Настройки ПК»: к защите и уборке добавлен раздел «Питание и экран». В
  профиле — `IdleShutdownMinutes` (5–720 или нет) и `ClubRules` (до 2000 знаков); у игры в
  библиотеке — «запускать в начале сессии».
- Простой считает агент: ПК заперт (не в сессии и не на обслуживании) и никто не трогал мышь —
  о вводе хост сообщает запросом `activity` не чаще раза в 20 секунд (служба в сессии 0 ввода не
  видит). Выключение назначается за минуту, экран свободного ПК показывает отсчёт, движение мыши
  отменяет его сразу (`shutdown /a`), простой начинается заново. Если выключатся все ПК зала,
  будить их некому — это написано у настройки.
- Правила клуба — в окне входа, свёрнутыми; автозапуск — после открытия ПК игроку, только в
  начале сессии; не запустилось — сессия всё равно идёт.

### P6d. Отзывы в Панели — сделано

Список отзывов филиала со средней оценкой, отбор по оценке; оценки с итога сессии на ПК — там же.

- `GET /api/organizations/{org}/branches/{branch}/reviews` — итог и разбивка по звёздам по всем
  оценкам филиала, отбор по звезде и «только с текстом», страница по 50 с курсором по времени, у
  каждого отзыва — ПК, за которым сидели. Право `organization.reviews.view` — владелец и
  управляющий: отзыв бывает и о смене.
- Панель «Управление → Отзывы»: полосы по звёздам — они же отбор.
- Названо, не сделано: ответ клуба на отзыв и скрытие оскорбительного — у отзыва нет ни ответа,
  ни модерации.
