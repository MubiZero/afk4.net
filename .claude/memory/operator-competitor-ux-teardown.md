**SmartShell — ключевые операторские паттерны (что взять):**
- **Карта/ПК = командный центр.** 2 вида: карта (`admin/map`) и таблица (`admin/computers`). ~10 статусов места (Выключен/Включён/Активный сеанс/Есть бронь/В обслуживании/Изменена конфигурация/Высокий доступ/Нет связи/Снят шелл/Заблокирован). **Строка критических состояний со счётчиками** (Высокий доступ / Нет связи / Снят шелл / В обслуживании + кол-во). **Технический режим редактирования карты**: drag элементов в ячейки — ПК/консоль/VR/симулятор/бильярд/настолки + стены/стрелки + зоны (ресепшен/гардероб/туалет/лаунж/бар/кухня) + текст-подписи. Правая панель: железо (CPU/RAM/GPU/HDD/занятость дисков/MAC/активное приложение/коммент) + **детект смены конфигурации → требует подтверждения менеджера**.
- **ПКМ контекст-меню на ПК:** Выбрать тариф · Пополнить депозит · Бронирование · **Штраф** · **Смена места (пересадка, в т.ч. между залами с приоритетами)** · Завершить сеанс · Уведомление · Электропитание · Управление ПК (вкл. удалёнка/просмотр экрана TightVNC) · Шелл. **Массовое выделение** (Shift/Ctrl/рамка) → массово продать тариф/забронировать/уведомить/питание.
- **Скорость:** глобальное «быстрое меню оператора» (кнопка «+») + хоткеи: `Ctrl+Alt+D` депозит, `Ctrl+Alt+P` высокий доступ, `Ctrl+Alt+L` язык.
- **Постановка сеанса:** ПКМ→Выбрать тариф→телефон (или пусто=гость)→тариф(ы)→оплата. Гость vs зарегистрированный.
- **Смена:** открыл = ввёл наличные на старте; в конце финотчёт/сверка.
- **Тариф = домен с визуальным языком инфо-иконок:** полумесяц=пересекает полночь, %=скидка применима, глаз=виден в шелле, монета=виден оператору при продаже, звезда=выделен в шелле, красный календарь=праздничный, самолётик=Telegram-уведомление, синий календарь=онлайн-бронь. 4 типа: фикс/пакет/поминутный/абонемент.
- **Лояльность = набор:** Скидка · Промокод (+группы массовой генерации) · Кешбэк · Достижения (конструктор условие→награда). Отдельные экраны `discounts`/`cashback`/`achievements`.
- **Логи:** универсальный поиск (телефон/товар/ПК), объект↔субъект, переключатель «все события / текущая смена», категории.
- **Настройки = вкладки:** Панель управления · Шелл · Кастомизация · SmartGamer (моб.прил/онлайн-бронь) · Интеграции · Безопасность. Богатые тумблеры: постоплата для гостей, виртуальные хосты, завершение сеанса до брони, вызов сотрудника из шелла, самопересадка.
- **Безопасность:** пароль высокого доступа, скрытие дисков, блокировка окон по классу, запрет внешних накопителей, удалёнка.
- **Прочее:** виджет «Чат поддержки» (низ-лево панели); 7 ролей с гибкими правами; единая база клиентов между клубами (депозит/бонус/скидка — пер-клуб).

**Langame — отличия:** финансовый хаб «Рабочее пространство управляющего» (9 под-отчётов: касса управляющего, лог кассовых операций, отчёты по сменам, обработка возвратов, инкассация терминалов, логи бонусов/финансов); **Тикеты**, История уведомлений, **Документы**, глубокий склад (заказы/оприходование/инвентаризация/списание/комбо/продажа по себестоимости).

**Наши gap-ы (приоритет для UI-редизайна):**
1. **Карта → командный центр** (зона №1): проверить/добавить ПКМ контекст-меню с полным набором операций, массовое выделение, строку критических состояний со счётчиками, режим редактирования карты, более богатую правую панель.
2. **Скорость рутины** (зона №2): глобальное быстрое меню «+» + хоткеи — у нас нет.
3. **Тариф** — поднять из Settings в операционный домен + визуальный язык статус-иконок.
4. **Логи** — универсальный поиск + объект/субъект.
**Фича-гэпы (НЕ UI, соседние продуктовые эпики):** промокоды/кешбэк/достижения, штраф, пересадка между залами, удалёнка TightVNC.

**Наши сильные стороны (фундамент сохранить):** real-time SignalR, offline-first (outbox+IndexedDB), error boundaries по воркспейсам, light/dark тема, ICU i18n ru/en/tg, dev-mock режим.

**Дип-ресёрч подтвердил/добавил (103 агента, 21 факт 3-0, 2026-06-14):**
- **СТРАТЕГ. ИНСАЙТ — роле-зависимая урезанная навигация.** Из офиц. функц-спеки SmartShell (PDF): панель **одноуровневая (flat)**. Менеджер видит 13 разделов (Дашборд/Компьютеры/Карта/Магазин/Платежи/Пользователи/Логи/Тарифы/Лояльность/Сотрудники/Контент/Отчёты/Настройки). **Оператор видит только 7** (Дашборд/Компьютеры/Карта/Магазин/Платежи/Пользователи/Логи) — Тарифы/Сотрудники/Настройки/Отчёты/Лояльность/Контент вырезаны. Т.е. рабочее место оператора ≠ админ-панель: surface скейлится под роль. Для нас — мысль: возможно показывать оператору меньше, чем менеджеру.
- **Быстрое меню оператора = 5 кассовых действий:** Пополнение депозита · Забронировать · Приходный ордер · Расходный ордер · Внесение на склад. (приходный/расходный ордер — у нас нет явно).
- **Смена:** открыть = ввод наличных + «Открыть смену»; закрыть = комментарий + **пароль оператора** + «Печать» (бумажный отчёт) + «Завершить».
- **Бронь:** отдельная вкладка с **тайм-чартом** (какие ПК на какое время заняты, имена клиентов) + 3 пути создания (вкладка / ПКМ на Компьютерах|Карте / быстрое меню); правка/удаление с Карты.
- **Отчёты = 7 штук:** продажи · смены · пользователи · посетители · занятость оборудования · бонусы · обзорный.
- **Langame нетто-ново:** Рассылки (messaging), Шкафчики (lockers) — отдельные модули.
- **ЧЕСТНОСТЬ (факты УБИТЫ верификацией, не утверждать):** «~45 тумблеров прав / гибкий RBAC за Business» — НЕ доказано (1-2); «3 операторские роли Оператор/Маркетолог/Менеджер» — ложь (0-3); Langame LanDesk-удалёнка — не доказано (1-2). 7 ролей у SmartShell — реально (из onboarding), но степень гранулярности прав не преувеличивать.
