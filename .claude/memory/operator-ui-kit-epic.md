Эпик: убрать «разрозненность» оператора вынесением языка эталона (Касса/Карта/Брони) в общий
слой атомов `.ui-*`. Начат с разбора экрана «Клиенты» (5 реализаций чипа, 6+ кнопок, 4+ карточки,
шкалы мимо токенов при живых `--space/--radius/--text/--font-mono`).

**Локнутые решения (брейншторм):**
1. Форма = общий CSS-слой `.ui-*` + тонкий React только для повторяющейся разметки (`Money`,
   `LedgerRow`). НЕ React-компоненты `<Button>/<Chip>` (весь проект = «голый элемент + класс»,
   0 React-обёрток).
2. Радиус = сходятся ВСЕ разделы, но слайсами по разделу; эталон мигрируется паритетом
   (после переименования классов вид тот же).
3. Клиенты = унификация + UX-фиксы §7.

**Файлы-каноны (в ветке `feat/operator-ui-kit` от `main`):**
- Спека: `docs/superpowers/specs/2026-07-01-operator-ui-kit-design.md`
- План S0+S1: `docs/superpowers/plans/2026-07-01-operator-ui-kit-s0-s1.md`

**Слайсы:** S0 (`styles/02-ui-kit.css` атомы btn/chip/card/field/money/ledger + `Money`/`LedgerRow`,
без визуальных изменений) → S1 (Клиенты) → S2 Склад → S3 Касса → S4 Карта → S5 Брони (S3–S5 паритет,
удаляют `pos-*`/`booking-*` дубли). `02-ui-kit.css` грузится в barrel `src/styles.css` после
`01-base`, до секционных → во время миграции секционные правила ещё выигрывают каскадом.

**Durable-факты из разведки:**
- Деньги: `formatMinorUnits(minorUnits, currencyCode)` (`currencyFormat.ts`, реэкспорт `operatorHelpers.ts:880`); minor units; эталон рендерит деньги/время `--font-mono` + `tabular-nums`.
- Строка операции живёт в 3 местах: `HistorySection`, мини-лента `WalletSection`, `ClientLedgerRail` (последний = обёртка над HistorySection) → один `LedgerRow`.
- §7.3 «зелёная точка Долги» = МИСРИД: счётчик уже `tone='warning'` (амбер), фейк-фикс не вносим.
- Дефолты полей кошелька заданы в `BackendPlayersWorkspace.tsx:53-56` (`useState('100.00')` и т.п.) → §7.5 меняет на пустые + placeholder.
- `StateFlag`/`.ui-chip--count` НЕ трогать в S1 (общий для Карты/Кассы) — отложено в кросс-секционный слайс.
