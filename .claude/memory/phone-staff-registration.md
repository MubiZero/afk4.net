**Decisions (locked):**
- Setup Wizard install = staff (owner + admins) sign in with **phone + password** (reuse existing opaque-token staff auth `/api/auth/staff/*`), NOT per-install SMS OTP. Owner-code stays as **fallback**.
- SMS (payom.tj) used only for: (a) verify staff phone at set/change; (b) password reset by SMS (alongside email). Not on each install.
- New permission `devices.install` → granted to owner/branch_manager/technician.
- Phone is a **global** login id (unique verified index), unlike username (per-org).
- Borrowed from SmartShell (competitor, support.smartshell.gg): phone=owner identity, admins self-serve installs, multi-method fallback. We're safer (no owner password on machines — each staff has own account).

**payom.tj API:** `POST https://gateway.payom.tj/api/message`, `Authorization: Bearer {token}`, body `{telephone:"+992…", text, senderName:"AFK4.NET", type:"SMS"}` → 201 `deliveryStatus:ACCEPTED`. Errors 422/401/403/500. SMS limit 153 latin / **67 Cyrillic** per segment → keep OTP ≤65, Cyrillic ok.
