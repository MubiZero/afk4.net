Когда пользователь просит «открой превью» (operator-web и т.п.) — он хочет посмотреть **сам в своём браузере**. Нужно поднять dev-сервер (`bun run dev` → `http://127.0.0.1:5174/`, превью-режим с моками включён по умолчанию) и дать ссылку + как дойти до нужного экрана. **Не** запускать headless-браузер (playwright/chromium) и не гонять скриншоты ради собственной проверки — это переусложнение, пользователь это явно остановил.

**Почему:** встроенный навык `run` требует «Drive it, don't just launch it… screenshot the window». Этот навык — системный бандл, его файл править бесполезно (перезапишется). Память приоритетнее навыка, поэтому правило живёт здесь.

**How to apply:** на «открой превью» — только запустить dev и отдать URL. Скриншотить через headless только если пользователь прямо просит скриншот/проверку глазами от меня.
