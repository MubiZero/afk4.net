**LOCKED-решения Этапа 0:**
- **Оболочка = вариант B «Evolve».** 3-зонный shell (рейл·рабочая·контекст) + 6-секционная IA. ДОБАВИТЬ: верх-полоса «+ Быстрое меню», поиск/палитра ⌘K, хоткеи, сворачиваемая контекст-панель, строка тревог в статус-баре. (Вариант C отвергнут.)
- **Командный слой:** «+» = 8 действий не привязанных к объекту (Запустить сессию/Продажа/Создать клиента/Новая бронь/Пополнить депозит/Приходный/Расходный ордер/Внесение на склад; смена НЕ тут — в профиле). ⌘K палитра = поиск сущности+переход+действие. Привязанные к ПК действия — на месте (клик/ПКМ), не в «+».
- **Визуальный язык места:** статус = спокойная база + полоса слева, громкий цвет только Внимание/Проблема; канон статусов (играют/внимание/проблема/свободно/бронь/обслуживание/выключен, не только цветом). Плитка = ОДИН размер, **density НЕТ**; предоплата=остаток времени внизу+бар, **постоплата=сумма вверх «54 с. ▲»**; свободно=«＋». Большой зал=скролл.
- **План зала:** виды **Сетка·План** (без «Оба»). План=холст сетка-снап, полная палитра (хосты/структура/зоны)+инспектор. Модель пола: место={x,y·тип·поворот·привязка·зона}, зона={прямоуг·тип·имя·цвет}, стена=отрезок. UI-редактор — в Этапе «Карта».

**РЕШЕНО в этой сессии (бывшие открытые вопросы):**
- **Роле-видимость = эталон-контракт «роль→секции» + guard-тест.** Механизм НЕ трогаем — навигация уже permission-driven (`canOpenWorkspace` по `session.permissions`, `operatorPermissions.ts`). 5 ролей: cashier_operator/shift_supervisor/branch_manager/technician/accountant_auditor. Таблица видимости в спеке §2 — ЦЕЛЕВОЙ контракт, сверить с бэкенд-маппингом прав (не подгонять под текущее, #37).
- **Дизайн-система = канон существующего, не изобретать.** Токены в `@afk4/tokens` уже сильные: типошкала 7 ступеней (11/13/14/16/20/26/32), motion (`--duration-fast 120`/`medium 200`/`modal 320` + ease-out/in/spring), focus-rings, **light в паритете с dark**. Примитивы: слой тонкий (`operatorPrimitives.tsx` = 3 шт; кнопки/таблицы/формы = CSS-классы в `styles.css` ~6500 строк). Решение: **«канон сейчас, извлечение по ходу»** (НЕ big-bang). Завести недостающие **Toast/Skeleton/EmptyState**. Motion-паттерны: feedback<100мс, optimistic (на offline-outbox), отложенный спиннер 150–300мс, скелетоны с финальной геометрией, prefers-reduced-motion.
- **Валюта = единый форматтер + знак (РЕАЛИЗОВАНО, в main).** Знак валюты — const-мапа `currencySymbol()` в `@afk4/money` (НЕ i18n-json: иначе пришлось бы тащить `t()` в десятки вызовов; знак НЕ язык-зависимый, TJS→«**с.**», USD→«$», фолбэк=код). Форматтер `formatMinorUnits` вынесен в листовой `src/AFK4.Operator.App.Web/src/currencyFormat.ts` (избегает цикла operatorHelpers↔floorMapState), реэкспортится из operatorHelpers; `formatMoney(null)`→ноль. Все money-surfaces (плитка/касса/платежи/клиенты/смены/ShopOrders/MapSidePanel) переведены на него, ISO-код «TJS» из UI убран. Десятичные: целое→0 знаков, дробное→до 2, ru-RU. Известный нюанс (вне скоупа): числовая локаль захардкожена `ru-RU`.

**ПРОЦЕССНЫЙ УРОК:** НЕ доводить дизайн попиксельно в HTML-мокапах (зарылись в «Карту» = ложный регресс). Решения — в спек, тонкую визуалику — в код этапа. Мокапов 1–2 на решение, не больше.
